# Solarius
Built an efficient waterless solar panel cleaning system to minimize manual effort.  Developed a mobile app that receives data from a PM2.5 dust sensor for real-time monitoring and  remote control; the project received funding of ₹4,500 under the 48th Series of SPP, KSCST.
